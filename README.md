# 递归不动点引擎实验室

一个零依赖的小型 Datalog 风格不动点引擎与静态对照页面。它支持多条递归规则、相互递归、含环关系图、半朴素增量传播、朴素执行对照，以及“全量去重索引 / 分段复核”两种内存策略。

## 运行

```bash
npm start
# 打开 http://localhost:4173
```

也可以直接用浏览器打开 `index.html`（脚本为经典脚本，不依赖 ES Module 服务）。

运行测试：

```bash
npm test
npm run check
```

## 页面能验证什么

- 左侧用文本编辑规则和本地表，可从内置样例替换，也可自由修改后运行。
- 同时执行：
  1. **朴素执行**：每轮用当前完整关系重算所有规则；
  2. **半朴素 + 全量去重索引**：只传播上一轮新增元组，全局 `Set` 去重；
  3. **半朴素 + 分段复核**：不保留全局去重索引，按固定容量分段复核；
  4. 一个故意漏掉 `Δ ⋈ Δ` 的错误版本，用于显示会缺少哪些元组。
- 页面展示每轮新增数量、候选量、扫描量、新增元组、差分标签、终止条件和最终关系集合。
- 可设置一条逻辑内存限额（MiB），比较两种去重方式的峰值内存、常驻索引、段复核次数和逐键比较次数。

## 输入语法

### 本地表

```prolog
table edge(src, dst) = {
  (1, 2),
  (2, 3),
  (3, 1)
}.
```

也支持直接事实：

```prolog
edge(1, 2).
color('alice', red).
```

### 规则

```prolog
reach(X, Y) :- edge(X, Y).
reach(X, Z) :- reach(X, Y), edge(Y, Z).

rpath(X, Z) :- rpath(X, Y), red(Y, Z).
bpath(X, Z) :- blue(X, Y), bpath(Y, Z).
bridge(X, Z) :- rpath(X, M), bpath(M, Z).
```

- 大写字母或 `_` 开头的标识符是变量；
- 小写标识符、数字、引号字符串是常量；
- 语句可以用 `.` 或 `;` 结束；
- 支持 `%`、`#`、`//`、`--` 注释；
- 目前只实现安全的正向规则，不支持否定和函数符号。

## 增量传播与 `Δ ⋈ Δ`

设第 `n` 轮的关系为 `I_n = I_{n-1} ∪ Δ_n`。对一条有 `k` 个递归原子出现的规则，引擎枚举这些递归原子使用 `old` 或 `Δ` 的所有非空子集：

```text
k = 2:
ΔR ⋈ Q_old
R_old ⋈ ΔQ
ΔR ⋈ ΔQ
```

最后一项保证：如果 `R` 和 `Q` 在同一轮两侧都新增了能在连接键上相接的元组，该推导不会被漏掉。即使同一递归谓词在规则体中出现两次，也按两个独立出现展开。

终止条件是某一轮没有任何新元组：

```text
Δ_{n+1} = ∅  ⇔  T(I_n) = I_n
```

无函数正向 Datalog 的常量域有限，而 `T` 单调；每一个非终止轮至少增加一个唯一元组，因此含环图也会到达不动点，不会沿环无限传播。

## 内存策略

内存数是引擎对元组、字符串、Set/Map 槽位、候选批和临时段索引的**显式逻辑估算**，不是浏览器 RSS。

### 全量去重索引

- 每个谓词保留一个常驻 `Set<tuple-key>`；
- 候选元组平均 `O(1)` 判重；
- 常驻索引内存随最终元组数线性增长；
- 超过限额时返回 `MEMORY_LIMIT` 和已完成轮次的部分结果。

### 分段复核

- 不保留全局 `Set`；
- 关系行按固定容量分段，候选先形成有界批次；
- 每一段可建立临时 `Set` 复核，结束后释放；
- 限额不足以建立临时段索引时退化为逐键比较；
- 用更多段复核和键比较换取更低的常驻去重内存。

在“内存索引压力样例（70×70）”中，将限额设为约 `0.75 MiB`，可以稳定看到全量索引触顶，而分段复核仍完成 4900 条 `pair` 关系。

## 文件

- `engine.js`：解析器、校验器、朴素/半朴素执行器、内存记账和集合比较；
- `samples.js`：内置样例与压力样例生成器；
- `app.js`：原生 DOM 渲染和交互；
- `index.html` / `styles.css`：无依赖页面；
- `server.js`：零依赖静态服务器；
- `test/engine.test.js`：Node 内置测试运行器测试。
